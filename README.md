# Healthcare Data Analytics Project

This project is a comprehensive healthcare data analytics system that processes patient datasets, performs exploratory data analysis using Pandas, and presents key insights through an interactive HTML dashboard.

## Project Structure
- `dataset/`: Contains the raw healthcare dataset.
- `Healthcaredatasetproject`: Jupyter Notebook containing Pandas data cleaning and visualization code.
- `HTML dashboard`: The interactive executive HTML dashboard.
- `README.md`: Project documentation.

## Key Features
- Cleaned and processed patient records using Python (Pandas).
- Visualized patient distribution across medical conditions, treatments, and metrics.
- Interactive HTML executive dashboard featuring dynamic data filters.

## Technologies Used
- **Python** (Pandas, Matplotlib) for data analysis and visualization.
- **HTML5, CSS3** for the interactive dashboard.
- **Jupyter Notebook** for development.

## How to View
1. Open the Jupyter Notebook (`Healthcaredatasetproject`) to review the Python/Pandas code and charts.
2. Open the `HTML dashboard` file in any web browser to explore the interactive dashboard.
